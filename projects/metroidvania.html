GAME DEVELOPMENT PROJECT

2D Metroidvania Game

A 2D action-platformer developed with Godot Engine and GDScript, featuring player movement, physics, animation, visual effects, and exploration-based gameplay.

×
ABOUT THE PROJECT

Building the Game

My Role

I developed this project as a game development exercise using the Godot Engine.

The project gave me practical experience implementing a controllable 2D character, physics-based movement, animations, jumping, gravity, collision detection, and visual effects.

I also worked with Godot's scene system, nodes, signals, and GDScript to organize the game's functionality.

Technologies

Godot Engine GDScript CharacterBody2D AnimatedSprite2D 2D Physics Game Development
DEVELOPMENT

Key Features

Some of the gameplay and programming concepts implemented in the project.

🎮

Character Controller

Implemented horizontal movement, jumping, gravity, and floor detection using CharacterBody2D.

🏃

Character Animation

Used AnimatedSprite2D to switch between idle, running, and jumping animations based on player movement.

✨

Visual Effects

Added visual effects for actions such as jumping and landing to make gameplay feel more responsive.
