IT Support Ticketing System

A web-based IT support ticketing application for organizing requests, tracking ticket status, and helping IT staff manage support tasks.

Project Overview

The IT Support Ticketing System is a help-desk web application built with Next.js and a MariaDB database. It provides a central dashboard for creating and managing IT support tickets.

The staff dashboard currently supports ticket creation, status updates, priority levels, assignment, search and filtering, ticket details, and deletion with confirmation. Client portal features should be described as complete only after they have been tested.

What I Built

I developed a ticket dashboard that helps organize IT requests and makes each ticket's status, priority, and assigned staff member easier to review.

I connected the application to MariaDB through Prisma to practice database-backed full-stack JavaScript development.

Key Features

  • Create IT support tickets
  • Update ticket status
  • Set ticket priority
  • Assign tickets to staff
  • Search and filter tickets
  • View ticket details
  • Delete tickets with confirmation
  • Prisma database integration

Development Process

I configured the Next.js App Router project and connected it to MariaDB using Prisma. I then implemented the main dashboard and its ticket-management actions.

The client portal can be documented in more detail once registration, login, client ticket submission, and replies are fully implemented and tested.

What I Learned

This project has helped me practice full-stack JavaScript, database modeling, and connecting frontend interfaces to backend routes.

It also gave me experience modeling help-desk workflows such as ticket status, priority, and assignment.
